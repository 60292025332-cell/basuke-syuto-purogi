# 🏀 バスケシューティングゲーム

ブラウザで遊べるバスケットボールのシューティングゲームです。

## 🎮 遊び方

1. **index.html** をブラウザで開く
2. 難易度（Easy / Normal / Hard）を選択
3. 「ゲームスタート」をクリック
4. マウスでゴールを狙い、**クリック長押し** → **離す** でシュート
   - 押している時間が長いほどパワーが強くなります
   - ゴールより高い位置にマウスを向けると放物線を描きます
5. 制限時間内にできるだけ多く得点を稼ごう！

## ✨ 主な機能

### 難易度3段階

| 難易度 | 特徴 |
|--------|------|
| **Easy** | ゴール固定・広いリム・40秒 |
| **Normal** | ゴールが横に動く・30秒 |
| **Hard** | ゴールが高速移動・風の影響あり・25秒 |

### ゲーム要素

- ⏱️ **タイマー**: 残り時間が10秒を切ると画面中央にカウントダウン表示
- 🔥 **コンボシステム**: 連続成功で得点が2倍、5連続で3倍！
- 💨 **風の影響**（Hard のみ）: ランダムに風向きが変化してボールの軌道が変わる
- 🎨 **パーティクルエフェクト**: ゴール成功時に華やかな演出
- 📊 **成績評価**: 成功率に応じて LEGENDARY / GREAT / GOOD などの評価

### 操作方法

- **マウス操作**: クリック長押し → 離す
- **タッチ操作**: タップ長押し → 離す（スマホ・タブレット対応）
- **パワーゲージ**: 画面下のバーで現在のパワーを確認

## 🎯 コツ

1. ゴールより**高い位置**にマウスを向けると弧を描いて飛びやすい
2. パワーゲージは**70〜90%** あたりが狙いやすい
3. Normal / Hard では**ゴールの移動先を予測**してシュート
4. Hard の風向き表示を見て**横風を計算**に入れる
5. コンボを繋げて**高得点**を狙おう

## 🛠️ 技術仕様

- **HTML5 Canvas** ベースのグラフィック
- **純粋な JavaScript**（ライブラリ不要）
- **レスポンシブデザイン**（モバイル対応）
- **物理演算**: 重力・風力・リムとの衝突判定
